# 黄祥云 · 个人作品集

面向产品与开发岗位的个人作品集，展示网页实践、交互原型与求职方向。

## 内容

- 响应式个人主页：教育背景、求职方向、作品与联系方式。
- Focus 任务看板：新增、搜索、状态切换、删除及浏览器本地保存。
- 产品原型实践：职向求职进度助手、拾光校园活动发现，展示目标用户、流程拆解、交互状态与验证计划。
- 可打印求职资料及 PDF 下载。
- 独立摄影作品集页面：访问 `/photo/` 浏览马拉松、自然与城市摄影作品。

产品原型为个人自主练习与代码实现的可点击概念稿，不代表商业项目、真实用户调研或过往实习经历。

## 本地预览

这是纯 HTML、CSS 和 JavaScript 网站，无需构建。可直接打开 `index.html`，也可使用任意静态文件服务器预览。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 `main` 分支和 `/ (root)`，保存后访问：

https://urmrh.github.io/yxm-portfolio/

该地址须在 GitHub Pages 发布成功后才可使用。自定义域名需另行配置 DNS 和 Pages 设置。

## 文件

- `index.html` / `styles.css` / `script.js`：主页。
- `demo.html` / `demo.css` / `demo.js`：任务看板。
- `prototype.html` / `prototype.css` / `prototype.js`：两个可点击的产品概念原型。
- `resume.html` / `huang-xiangyun-resume.pdf`：求职资料。
- `icon.svg`：网站图标。
- `photo/index.html` / `photo/assets/`：摄影作品集页面与照片素材。

任务仅保存在当前浏览器，不上传到服务器。仓库不包含服务器密码、证书私钥及服务器运维配置。
